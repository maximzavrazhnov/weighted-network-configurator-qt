# Weighted Network Configurator — C++ / Qt

Учебно-исследовательский desktop-прототип из магистерского проекта для
**перебора, ранжирования и визуализации допустимых конфигураций взвешенной сети**
при ограничениях на число связей каждого участника.

## Что делает программа

Для каждого участника задаются:

- требуемое число связей;
- допустимые контрагенты/связи;
- вес каждой допустимой связи.

Рекурсивный алгоритм перебирает допустимые неориентированные конфигурации,
проверяет ограничения, считает суммарный вес и сортирует решения. Qt-интерфейс
позволяет вводить матрицу вручную и просматривать найденные графы.

## Что показывает проект

- C++17;
- Qt Widgets;
- структуры данных для графоподобной модели;
- рекурсивный комбинаторный поиск;
- проверку ограничений;
- ранжирование решений;
- графическую визуализацию;
- перенос старого Visual Studio/Qt-проекта на CMake.

## Важное про исходники

`legacy/original-source/` содержит исходный код из архива без смысловой
переработки.

`src/` — публичная версия с небольшими техническими исправлениями:
const-correctness, стандартные copy/move semantics, защитные проверки и
портируемая CMake-структура.

Подробности — в `docs/PROJECT_HISTORY.md`.

## Сборка без Qt

```bash
cmake -S . -B build -DBUILD_QT_GUI=OFF
cmake --build build
ctest --test-dir build --output-on-failure
```

## Сборка GUI

Нужен Qt 6 Widgets:

```bash
cmake -S . -B build -DBUILD_QT_GUI=ON
cmake --build build
```

Проект является академическим прототипом, а не production-библиотекой.
