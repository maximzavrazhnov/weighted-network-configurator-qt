# How to add a GitHub profile README

GitHub displays a special README at the top of your profile when you create a
**public repository whose name is exactly the same as your GitHub username**.

For your account:

`maximzavrazhnov`

## Steps

1. Open GitHub and click **New repository**.
2. Repository name: `maximzavrazhnov`
3. Set it to **Public**.
4. GitHub may show a message that this is a special profile repository.
5. You can initialize this repository with a README.
6. Open `docs/PROFILE_README_TEMPLATE.md` from this package.
7. Copy its contents into the profile repository's `README.md`.
8. Commit with:

`Add technical profile README`

## Recommended order

Create/upload the four portfolio repositories first, then publish the profile
README. That way every project link works immediately.
